Projects

BIP 360 + bip360.org, a proposed Bitcoin soft fork that would add a post-quantum output type (P2MR). That is cryptography meant to remain sound if large quantum computers exist. It is not a quantum computer.

Grok OSS, an open source Grok Build fork that accepts pull requests. It is a harness. It is not yet an operating system. It will help us bootstrap a provably perfect OS (best we can, despite everything): the most absurdly paranoid and hardened OS that is still computationally efficient.

libbitcoinpqc + bindings, a post-quantum cryptography library for Bitcoin signatures; bindings by Jeff Bride. It is not a quantum computer.

Post-quantum cryptography is not quantum computing. BIP 360 and libbitcoinpqc are not optical computers, neuromorphic in-memory computers, or quantum computers.

Systems Lean, Lean 4 with linear types for systems programming.

People who ship with us are on Contributors. The aims those projects serve are on Philosophy.
